## Observed documentation inconsistencies

- Agents limits page states 1 GB per Agent; Durable Objects documentation states 10 GB on Paid and 1 GB on Free. Design conservatively and verify the actual binding and plan.
- The Workflows concurrency table and some explanatory prose show different values. Do not turn the larger value into a service promise.
- Think overview documents AI SDK 6/7 combinations; the current `@cloudflare/think@0.20.0` registry peer dependencies require AI SDK 7. Installed declarations and a locked build are required before implementation acceptance.

## Evidence interpretation

Public product documentation establishes an advertised API or limit at an observation date. Package metadata establishes a registry version. A local compile establishes a local build. Only appropriately scoped live tests establish that a given Cloudflare account, model credential, environment, or device actually supports a scenario.
